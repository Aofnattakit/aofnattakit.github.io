# แฟ้มผลงานครูนัฎฐกิตติ์ — คู่มือติดตั้งและดูแลเว็บ

เว็บนี้แบ่งเป็น 3 ส่วนที่ทำงานร่วมกัน

| ส่วน | อยู่ที่ไหน | ทำหน้าที่ |
|---|---|---|
| **ฐานข้อมูล** | Google Sheet ของครู | เก็บผลงาน ความเคลื่อนไหว หมวดหมู่ และข้อความบนเว็บ |
| **หลังบ้าน + หน้าโพสต์** | Apps Script ใน Sheet เดียวกัน | ส่งข้อมูลให้เว็บ และเปิดหน้าโพสต์ด่วนบนมือถือ (เก็บรูปใน Google Drive) |
| **หน้าเว็บสาธารณะ** | GitHub Pages | หน้าที่คนทั่วไปเห็น ลิงก์ประมาณ `https://ชื่อผู้ใช้.github.io` |

ข้อมูลแยกจากหน้าตาเว็บ อยากเปลี่ยนดีไซน์ในอนาคตก็เปลี่ยนเฉพาะไฟล์หน้าเว็บ (`index.html`, `assets/`) ข้อมูลในชีตไม่ต้องแตะ

```
(ราก repo บน GitHub = หน้าเว็บ)
├─ index.html
├─ config.js          ★ ไฟล์เดียวที่ต้องแก้ตอนติดตั้ง
├─ assets/style.css   หน้าตาเว็บ (สี ฟอนต์ เลย์เอาต์)
├─ assets/app.js      การทำงานของเว็บ
├─ assets/fx.js       เอฟเฟกต์เคลื่อนไหว
├─ assets/teacher.webp รูปครูแบบลบพื้นหลัง
├─ data/sample.json   ข้อมูลสำรอง ใช้ตอนยังไม่เชื่อม Sheet
├─ apps-script/       ← สำเนาโค้ดหลังบ้าน คัดลอกไปวางใน Apps Script
│  ├─ Code.gs  ├─ Seed.gs  └─ Admin.html
├─ README.md          คู่มือนี้
├─ CLAUDE.md          สมุดบันทึกให้ Claude อ่านก่อนช่วยแก้เว็บ
└─ .nojekyll
```

## ขั้นที่ 1 · สร้าง Google Sheet และใส่ระบบหลังบ้าน (ประมาณ 10 นาที)

ใช้ **บัญชี Google ส่วนตัว** ทุกขั้นตอน

1. เปิด [sheets.new](https://sheets.new) ตั้งชื่อไฟล์ว่า `แฟ้มผลงานครู`
2. เมนู **ส่วนขยาย › Apps Script**
3. ในหน้า Apps Script
   - ไฟล์ `Code.gs` ที่มีอยู่ ลบข้อความเดิมทิ้ง แล้ววางเนื้อหาจาก `apps-script/Code.gs`
   - กด **＋ › สคริปต์** ตั้งชื่อ `Seed` แล้ววางเนื้อหาจาก `apps-script/Seed.gs`
   - กด **＋ › HTML** ตั้งชื่อ `Admin` (ห้ามพิมพ์ .html ต่อท้าย) แล้ววางเนื้อหาจาก `apps-script/Admin.html`
   - กดไอคอนบันทึก 💾
4. กลับไปที่ Google Sheet แล้ว **รีเฟรชหน้า** จะมีเมนู **แฟ้มผลงาน** ขึ้นที่แถบด้านบน
5. กด **แฟ้มผลงาน › ตั้งค่าครั้งแรก / อัปเกรดโครงสร้าง**
   - Google จะขอสิทธิ์ ให้กด **ดำเนินการต่อ** › เลือกบัญชี › ถ้าเห็นคำว่า "Google ไม่ได้ยืนยันแอปนี้" กด **ขั้นสูง › ไปที่ (ชื่อโปรเจกต์)** › **อนุญาต** (เป็นสคริปต์ของครูเอง จึงขึ้นคำเตือนนี้ตามปกติ)
   - กดเมนูซ้ำอีกครั้ง ระบบจะสร้างแท็บ `items` `categories` `settings` โฟลเดอร์รูปใน Drive และแสดง **รหัสสำหรับโพสต์ 8 หลัก** ให้จดไว้

## ขั้นที่ 2 · เปิดใช้งานเป็นเว็บแอป

1. ในหน้า Apps Script กด **ทำให้ใช้งานได้ › การทำให้ใช้งานได้รายการใหม่**
2. กดไอคอนเฟือง ⚙ เลือก **เว็บแอป**
3. ตั้งค่า
   - คำอธิบาย: `v1`
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
4. กด **ทำให้ใช้งานได้** แล้วคัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`)

> "ทุกคน" หมายถึงเว็บสาธารณะอ่านข้อมูลได้ ส่วนการโพสต์ แก้ไข ลบ ต้องใช้รหัส 8 หลักทุกครั้ง
> รายการที่ติ๊ก "ซ่อนไว้ก่อน" และชื่อนักเรียนที่ไม่ได้เปิดให้แสดง จะไม่ถูกส่งออกไปที่หน้าเว็บ

## ขั้นที่ 3 · ขึ้นเว็บด้วย GitHub Pages (ประมาณ 10 นาที)

1. สมัครบัญชีที่ [github.com](https://github.com) ชื่อผู้ใช้จะกลายเป็นชื่อเว็บ เช่น ชื่อผู้ใช้ `krunattakit` → เว็บ `https://krunattakit.github.io`
2. กด **＋ › New repository** ตั้งชื่อเป็น **`ชื่อผู้ใช้.github.io`** (ต้องตรงทุกตัวอักษร) เลือก **Public** › **Create repository**
3. กดลิงก์ **uploading an existing file** แล้วลาก **ทุกไฟล์และโฟลเดอร์ที่อยู่ในโฟลเดอร์ที่แตก zip ออกมา** ลงไปทั้งหมด (ลากของข้างใน ไม่ใช่ลากตัวโฟลเดอร์ ให้ `index.html` อยู่ชั้นนอกสุดของ repo) › **Commit changes**
   - ไฟล์ `.nojekyll` อาจถูกซ่อนบนคอมพิวเตอร์ ถ้าลากไม่ติดก็ไม่เป็นไร
4. เปิดไฟล์ `config.js` ในหน้า GitHub › กดรูปดินสอ ✏️ › วาง URL จากขั้นที่ 2 ระหว่างเครื่องหมายคำพูด
   ```js
   API_URL: "https://script.google.com/macros/s/xxxx/exec"
   ```
   › **Commit changes**
5. ไปที่ **Settings › Pages** › Source: **Deploy from a branch** › Branch: **main** / **(root)** › **Save**
6. รอ 1–2 นาที แล้วเปิด `https://ชื่อผู้ใช้.github.io`
7. กลับไปที่ Google Sheet แท็บ `settings` ใส่ลิงก์เว็บในแถว `siteUrl` (หน้าโพสต์จะมีปุ่ม "ดูบนเว็บ")

## ขั้นที่ 4 · ตั้งหน้าโพสต์บนมือถือ

1. เปิด URL เว็บแอปจากขั้นที่ 2 ในมือถือ (Chrome หรือ Safari) แล้วใส่รหัส 8 หลัก
2. เพิ่มเป็นไอคอนบนหน้าจอ
   - **Android (Chrome):** เมนู ⋮ › เพิ่มลงในหน้าจอหลัก
   - **iPhone (Safari):** ปุ่มแชร์ › เพิ่มไปยังหน้าจอโฮม
3. ครั้งต่อไปกดไอคอนแล้วโพสต์ได้ทันที

### ตัวอย่าง: พานักเรียนไปประกวดแล้วโพสต์ทันที
กดไอคอน › แท็บ **โพสต์ด่วน** › **เพิ่มรูป** (ถ่ายใหม่หรือเลือกจากอัลบั้ม) › เลือกประเภท **พานักเรียนแข่งขัน** › พิมพ์หัวข้อและชื่องาน › เลือกระดับ › กดผลที่ได้ เช่น **เหรียญทอง** › **โพสต์เลย**
เว็บจะแสดงโพสต์ในส่วน "ความเคลื่อนไหวล่าสุด" พร้อมป้ายเหรียญสีทอง และในหน้ารายละเอียดมีปุ่ม **แชร์** สำหรับส่งลิงก์ไปที่ LINE หรือ Facebook

## ระบบอ่านเกียรติบัตรอัตโนมัติ (เวอร์ชัน 1.1)
ในหน้าโพสต์ แท็บ **โพสต์ด่วน** พอใส่รูปเกียรติบัตร (หรือแนบ PDF) จะมีปุ่มสีทอง **อ่านข้อมูลจากเกียรติบัตร** กดแล้วระบบกรอกหัวข้อ ประเภท ชื่องาน วันที่ ระดับ ผลรางวัล ชื่อผู้ได้รับ และรายละเอียดให้ ช่องที่ระบบกรอกจะเป็นสีเหลือง ตรวจทานก่อนกดโพสต์

มีตัวอ่าน 2 แบบ ระบบเลือกให้อัตโนมัติ
| ตัวอ่าน | ต้องตั้งค่า | ความแม่นยำ |
|---|---|---|
| **AI Gemini** (แนะนำ) | ใส่คีย์ API ฟรีจาก [aistudio.google.com/apikey](https://aistudio.google.com/apikey) ผ่านเมนู **แฟ้มผลงาน › ตั้งค่า AI อ่านเกียรติบัตร (Gemini)** | สูง เข้าใจบริบท เขียนหัวข้อและสรุปให้ |
| **ตัวอ่านของ Google Drive** (สำรอง) | ไม่ต้อง ใช้เมื่อยังไม่มีคีย์หรือ AI ขัดข้อง | พื้นฐาน อ่านตัวอักษรแล้วแยกด้วยกฎภาษาไทย อาจต้องแก้บางช่อง |

**ความเป็นส่วนตัว:** เกียรติบัตรมีชื่อนักเรียน ถ้าใช้คีย์ Gemini แบบฟรี Google อาจนำข้อมูลที่ส่งไปใช้ปรับปรุงบริการ ถ้ากังวล ให้ใช้ตัวอ่านของ Google Drive (ข้อมูลอยู่ใน Drive ของครู ไฟล์ชั่วคราวถูกลบทันที) หรือเปิดการเรียกเก็บเงินในบัญชี AI Studio (ระดับเสียเงินไม่นำข้อมูลไปใช้ฝึก) · ชื่อนักเรียนที่อ่านได้ยังไม่แสดงบนเว็บ จนกว่าจะเปิดสวิตช์ "แสดงชื่อนักเรียนบนเว็บ"

เปลี่ยนรุ่นโมเดล: ใน Apps Script › ⚙ การตั้งค่าโปรเจ็กต์ › Script Properties เพิ่ม `GEMINI_MODEL` (ค่าเริ่มต้น `gemini-flash-latest`)

## การใช้งานประจำ

| อยากทำ | ทำที่ |
|---|---|
| โพสต์ข่าว รางวัล อบรม | หน้าโพสต์ › แท็บ **โพสต์ด่วน** |
| เพิ่มผลงานใหม่ (เกม สื่อ ระบบ เอกสาร) | หน้าโพสต์ › แท็บ **เพิ่มผลงาน** |
| แก้ไข ลบ ปักหมุดผลงานเด่น เพิ่มรูป | หน้าโพสต์ › แท็บ **รายการ** › กดที่รายการ |
| แก้ข้อความบนเว็บ (หัวเรื่อง แนะนำตัว ทักษะ) | Google Sheet แท็บ `settings` |
| เพิ่ม/เปลี่ยนชื่อหมวดหมู่ | Google Sheet แท็บ `categories` (ดูด้านล่าง) |
| แก้หลายรายการพร้อมกัน | Google Sheet แท็บ `items` แล้วกด **แฟ้มผลงาน › อัปเดตหน้าเว็บทันที** |
| ลืมรหัส / เปลี่ยนรหัส | Google Sheet เมนู **แฟ้มผลงาน › ดูรหัส** หรือ **ตั้งรหัสใหม่** |

- โพสต์จากหน้าโพสต์จะขึ้นเว็บภายในไม่กี่วินาที
- แก้ไขในชีตโดยตรง ระบบใช้แคชไว้ไม่เกิน 6 ชั่วโมง กด "อัปเดตหน้าเว็บทันที" เพื่อให้ขึ้นทันที

### ข้อความในแท็บ `settings`
| key | ใช้ทำอะไร |
|---|---|
| `name` `role` `school` `office` | ชื่อ ตำแหน่ง โรงเรียน สังกัด |
| `heroTitle` | หัวเรื่องตัวใหญ่ ใช้ `\|` ขึ้นบรรทัดใหม่, `[คำ]` ให้เป็นสีทอง, `{บรรทัด}` ให้เป็นบรรทัดตัวเล็ก เช่น `แฟ้มผลงาน\|[ครูนัฎฐกิตติ์ เพชรี]\|{กลุ่มสาระการเรียนรู้คณิตศาสตร์}` |
| `tagline` | ข้อความตัวเขียนลายมือใต้หัวเรื่อง |
| `intro` | ข้อความแนะนำตัว |
| `phone` `email` `line` `facebook` | ช่องทางติดต่อในกล่องสีเขียว (เว้นว่าง = ไม่แสดง) |
| `cta` | ข้อความชวนติดต่อท้ายเว็บ |
| `skills` | ความถนัด คั่นด้วยจุลภาค แสดงเป็นไอคอนในกล่องสีเขียว (ไอคอนเลือกให้อัตโนมัติ) |
| `avatar` | รูปครูบนวงกลมสีทอง: ใช้รูปที่ **ลบพื้นหลังแล้ว (PNG)** เช่น ลบด้วย Canva แล้วอัปโหลดขึ้น Drive (แชร์แบบทุกคนที่มีลิงก์) แล้ววางรหัสไฟล์หรือลิงก์รูป · ค่าเริ่มต้นคือ `assets/teacher.webp` (รูปที่ลบพื้นหลังไว้แล้วในชุดไฟล์) · เปลี่ยนรูปได้โดยอัปโหลดไฟล์ใหม่ชื่อเดิมทับใน GitHub · เว้นว่าง = แสดงรูปทรงคณิตศาสตร์หมุนแทน |
| `canvaUrl` | ลิงก์ปุ่ม "เว็บสื่อการสอน" (เว้นว่าง = ซ่อนปุ่ม) |
| `siteUrl` | ลิงก์เว็บ GitHub Pages |
| `footer` | ข้อความตัวเขียนบรรทัดล่างสุดของเว็บ |

> ถ้าติดตั้งเวอร์ชันก่อนหน้าไปแล้ว ให้เพิ่มแถว key ข้างบนที่ยังไม่มีลงในแท็บ `settings` เอง

### เปลี่ยนสีทั้งเว็บ
สีหลักทั้งหมดอยู่ด้านบนของไฟล์ `assets/style.css` (`--forest` = เขียวเข้ม, `--gold` = เหลืองทอง, `--paper` = สีพื้นกระดาษ) แก้ที่นี่ที่เดียว ทั้งเว็บจะเปลี่ยนตาม
| key ที่ขึ้นต้นด้วย `_` | ใช้ภายใน ไม่ส่งไปหน้าเว็บ |

### แท็บ `categories`
| คอลัมน์ | ความหมาย |
|---|---|
| `key` | รหัสภาษาอังกฤษ ไม่ซ้ำ ไม่มีเว้นวรรค (ห้ามเปลี่ยนถ้ามีผลงานใช้อยู่แล้ว) |
| `type` | `work` = หมวดผลงาน · `news` = ประเภทความเคลื่อนไหว |
| `name` | ชื่อที่แสดง เปลี่ยนได้ทุกเมื่อ |
| `color` | สี เช่น `#2563eb` |
| `icon` | ภาพประกอบ เลือกจาก `game` `app` `media` `doc` `activity` `design` `award` `pd` |
| `order` | ลำดับการแสดง |

## การปรับปรุงในอนาคต

### อัปเดตโค้ดหลังบ้าน (สำคัญ: ทำแบบนี้เพื่อให้ลิงก์เดิมใช้ได้ต่อ)
1. วางโค้ดใหม่ใน Apps Script › บันทึก
2. **ทำให้ใช้งานได้ › จัดการการทำให้ใช้งานได้** › กดดินสอ ✏️ › เวอร์ชัน: **เวอร์ชันใหม่** › **ทำให้ใช้งานได้**
3. ถ้าเวอร์ชันใหม่เพิ่มคอลัมน์ ให้กด **แฟ้มผลงาน › ตั้งค่าครั้งแรก / อัปเกรดโครงสร้าง** อีกครั้ง ระบบจะเติมคอลัมน์ใหม่ให้โดยไม่ลบข้อมูลเดิม

> ห้ามกด "การทำให้ใช้งานได้รายการใหม่" ซ้ำ เพราะจะได้ URL ใหม่ แล้วต้องไปแก้ `config.js` และไอคอนบนมือถือใหม่ทั้งหมด

### ปรับหรือปิดเอฟเฟกต์เคลื่อนไหว
เปิดไฟล์ `assets/fx.js` แก้ค่าในส่วน `FX` ด้านบน เช่น `bgDensity: 0.5` ให้สัญลักษณ์บนพื้นหลังน้อยลง หรือ `burst: false` ปิดประกายตอนกด ถ้าอยากปิดทั้งหมด ให้ลบบรรทัด `<script src="assets/fx.js" defer></script>` ใน `index.html` ผู้ใช้ที่ตั้งเครื่องให้ "ลดการเคลื่อนไหว" จะเห็นเว็บแบบนิ่งโดยอัตโนมัติ

### อัปเดตหน้าตาเว็บ
แก้หรืออัปโหลดไฟล์ใหม่ทับใน GitHub (`assets/style.css` สำหรับหน้าตา, `assets/app.js` สำหรับการทำงาน) ทุกการแก้ไขมีประวัติใน GitHub ย้อนกลับได้เสมอ ส่วน `config.js` ไม่ต้องแก้

### ให้ Claude แก้เว็บให้โดยตรง
เปิดแชตกับ Claude แล้วบอกชื่อ repo (เช่น `ชื่อผู้ใช้/ชื่อผู้ใช้.github.io`) พร้อมสิ่งที่อยากเปลี่ยน Claude จะขอสิทธิ์เข้าถึง repo (ครูกดอนุญาตครั้งแรกครั้งเดียว) อ่าน `CLAUDE.md` แก้โค้ด ส่งภาพตัวอย่าง แล้วส่งขึ้นเว็บให้ ถ้า Claude แจ้งว่ายังไม่ได้เชื่อม GitHub ให้ไปที่ claude.ai › Settings › Connectors › GitHub

### เปลี่ยนเป็นโดเมนของตัวเอง (ทำเมื่อไหร่ก็ได้)
ซื้อโดเมน เช่น `krunattakit.com` › ใน GitHub ไปที่ **Settings › Pages › Custom domain** › ตั้งค่า DNS ตามที่ GitHub บอก › แก้ `siteUrl` ในชีต ลิงก์เก่า `.github.io` จะพาไปโดเมนใหม่ให้อัตโนมัติ

### ฟีเจอร์ที่วางช่องไว้แล้ว
- **AI ช่วยเขียนโพสต์:** เพิ่มปุ่มในหน้าโพสต์ที่ส่งข้อความสั้น ๆ ไปเรียบเรียง ต้องใช้ API key ซึ่งเก็บใน Script Properties ได้อย่างปลอดภัย
- **หน้าสรุปหลักฐาน ว PA / DPA รายปี:** ข้อมูลมีคอลัมน์ `pa` และ `year` อยู่แล้ว สร้างหน้าสรุปหรือส่งออกเป็นเอกสารได้ทันที
- **ภาษาอังกฤษ / หลายหน้า:** เพิ่มคอลัมน์ เช่น `title_en` ในชีต แล้วกดอัปเกรดโครงสร้าง

## ข้อควรระวัง
- **รูปและชื่อนักเรียน:** นักเรียนเป็นผู้เยาว์ ควรขอความยินยอมตามแนวปฏิบัติของโรงเรียนก่อนเผยแพร่ ช่อง "แสดงชื่อนักเรียนบนเว็บ" ปิดไว้เป็นค่าเริ่มต้น
- **รหัสโพสต์:** อย่าแชร์ให้ผู้อื่น ถ้าสงสัยว่ารั่ว ให้กด **ตั้งรหัสโพสต์ใหม่**
- **บัญชีที่ใช้:** ใช้บัญชี Google ส่วนตัว เพื่อให้ข้อมูลอยู่กับครูแม้ย้ายโรงเรียน
- **รูปไม่ขึ้น:** ตรวจว่าไฟล์ใน Drive แชร์แบบ "ทุกคนที่มีลิงก์" (ระบบตั้งให้อัตโนมัติตอนอัปโหลด)
